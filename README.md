#Assignment-06

This project is a responsive fitness/workout management web application built with Next.js, TypeScript, Tailwind CSS, and DaisyUI. Users can browse workout exercises, view detailed workout information, save exercises for later, and add exercises to their daily plan.

*Works smoothly on mobile, tablet, and desktop screen sizes.
*Users can browse available workout/exercise cards.
*Users can view detailed information about each exercise.
* Users can add exercises to their daily workout plan.
*Users can save exercises and access them from the Saved tab.
*Automatically calculates total exercises, minutes, and calories.
*Users can sort workouts by duration or calories burned.
* Prevents the same workout from being added to a plan or saved multiple times.
